
# LEO-Link

An end-to-end satellite communications and digital signal processing simulator developed primarily in Python.

## Project Overview

LEO-Link will simulate the transmission of digital data from a low-Earth-orbit satellite to a ground station.

The project will investigate how channel noise, Doppler shift, and changing link conditions affect communication reliability.

## Project Objectives

- Implement BPSK and QPSK digital modulation.
- Model communication channel impairments.
- Develop a digital receiver for signal recovery.
- Evaluate bit error rate (BER) and link performance.
- Validate selected models in MATLAB/Simulink.
- Visualize satellite communication scenarios in Blender.

## Technologies

- Python, NumPy, SciPy, Matplotlib
- MATLAB / Simulink
- Blender
